# Logo Setup

Place your logo files in this folder before running the project.

## Required files

| Filename         | What it is                              |
|------------------|-----------------------------------------|
| `aivora-logo.png` | The AIVORA logo (with tagline image)   |
| `bvrit-logo.png`  | The BVRIT Hyderabad college logo       |

## How

1. Save the AIVORA logo image as:   `public/logos/aivora-logo.png`
2. Save the BVRIT logo image as:    `public/logos/bvrit-logo.png`

Both logos are used in the Navbar, Hero section, and Footer.
If either file is missing, a text/SVG fallback is shown automatically.

## Recommended formats

- PNG with transparent background preferred
- JPG also works
- Max size: 500 KB each (they're loaded on every page)
